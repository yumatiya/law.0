# Law.Gen - AI-Powered Education Platform

> Complete Education Solution from Class 9 to PhD with AI Tutoring & 3D Interactive Learning

## 🎓 About

Law.Gen is a comprehensive educational platform that provides:
- **All Education Levels**: Class 9-10, 11-12, Undergraduate, Postgraduate, PhD
- **AI-Powered Tutoring**: Personalized learning with Claude AI
- **3D Interactive Content**: Immersive 3D models and videos
- **Multi-Language Support**: English, Hindi, Gujarati
- **Complete Subject Coverage**: Science, Engineering, Medical, Commerce, Arts, Law

## 🚀 Features

- 🎬 Interactive 3D Video Player
- 🤖 AI Chat Assistant
- 📚 Comprehensive Subject Library
- 🎯 Smart Quiz System
- 📊 Progress Tracking
- 🏆 Gamification
- 🔐 Secure Authentication

## 💻 Technology Stack

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma ORM
- **Database**: PostgreSQL
- **AI**: Anthropic Claude API
- **3D Graphics**: Three.js, React Three Fiber

## 📦 Installation
```bash
# Clone the repository
git clone your-repo-url
cd law-gen

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env
# Add your API keys to .env

# Setup database
npx prisma generate
npx prisma db push

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
